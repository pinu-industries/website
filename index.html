Proyectos

Lo que hemos construido

Proyectos reales que nuestro equipo ha desarrollado para organizaciones de Querétaro.

Un sistema para administrar al personal de la red desde un solo lugar.

  1. Problema

    La información de empleados, vacaciones y ausencias se llevaba por separado y dependía de quien la administraba. Era difícil tener una vista completa del personal.

  2. Solución

    Un sistema de recursos humanos para gestionar empleados, vacaciones, ausencias y eventos de la organización, con permisos por tipo de usuario, verificación en dos pasos y registro de quién hizo cada cambio.

  3. Resultado

    La información del personal ahora está centralizada, protegida y con historial de actividad.

  4. Tecnología

    App web publicada en internet, con base de datos y acceso por roles.

    • React
    • Node.js
    • Express
    • SQL
    • Prisma
    • Hostinger
    • Cloudflare

Una plataforma clínica con app para pacientes y panel web para doctores y administradores.

  1. Problema

    Los expedientes, las citas, los resultados de los pacientes y la información del personal no estaban en un mismo sistema, lo que hacía más lento el seguimiento.

  2. Solución

    Dos piezas conectadas: una app para iPhone con citas, resultados médicos y comunidad, y un panel web donde doctores y administradores gestionan expedientes y personal.

  3. Resultado

    Pacientes, doctores y administradores trabajan sobre el mismo sistema, y cada usuario accede solo a lo que le corresponde según su rol para proteger la información médica.

  4. Tecnología

    App para iPhone y panel web, conectados a un sistema central con base de datos.

    • Swift
    • SwiftUI
    • React
    • Node.js
    • Express
    • TypeScript
    • SQL
    • Prisma

Un sistema de recursos humanos hecho a la medida de la empresa.

  1. Problema

    La empresa necesitaba gestionar a su personal con procesos propios que las herramientas genéricas no cubrían.

  2. Solución

    Un sistema web de recursos humanos adaptado a su forma de trabajar: empleados y departamentos, vacaciones, eventos, días feriados y agenda de reuniones one-on-one.

  3. Resultado

    Cada usuario ve solo lo que le corresponde gracias a los permisos por rol, y el equipo lo usa desde cualquier lugar porque vive en la nube.

  4. Tecnología

    App web en la nube, accesible desde cualquier computadora.

    • EJS
    • Tailwind CSS
    • JavaScript
    • Node.js
    • Express
    • SQL
    • AWS
